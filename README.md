Two days on Earth, one field note. The locals set a cake on fire, make a
silent wish to it, blow it out, then eat it — and the cake grants nothing.

`main.py` (pure Python standard library, `os` only) writes exactly one line
— 131 characters — an alien tourist's review of Earth, to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same line, byte for byte, on every run.
